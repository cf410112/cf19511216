# 雲鵬住宿式長照機構設立規劃

本專案整理地上1–7樓建築物轉作住宿式長照機構的床數、樓地板面積、寢室、活動空間、隔離室及長期臥床專區法規檢核。

## 現行規劃基準

- 總樓地板面積：2,441.84㎡
- 核准床數：150床
- 2樓：20床
- 3–7樓：各26床，共130床
- 1樓：另設2間非核准床隔離室
- 收案對象：植物人或長期臥床（含重癱）專區／專責服務

## 主要文件

- `住宿式長照機構_150床加2間隔離室面積檢核.md`：目前的床數與面積檢核基準。
- `住宿式長照機構_130床容量配置說明.md`：較早期的130床容量配置研究。
- `住宿式長照機構_130床概念配置圖.svg`：可編輯向量配置草圖。

- `住宿式長照機構_100床概念配置圖.png`：歷史版本。

## 注意事項

這些文件屬前期可行性研究，不是建築師簽證、消防、施工或正式送審圖。正式申請仍須依使用執照、核准竣工圖、現況測量、消防避難及苗栗縣主管機關審查結果調整。
